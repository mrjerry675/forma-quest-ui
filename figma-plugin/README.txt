FORMA + QUEST — FIGMA GENERATOR

Import manifest.json using the Figma desktop app:
Open a Design file > right-click canvas > Plugins > Development > Import plugin from manifest.
Run "Forma + Quest — Editable UI Prototypes" from Development or the Actions menu.

The plugin creates a new page with:
- 8 Forma desktop screens
- 10 Quest desktop screens
- 2 mobile entry screens
- Button, Input, and Achievement badge component sets
- Auto Layout, editable text, and Smart Animate navigation
- Four named prototype starting points

Select the Forma or Quest starting flow and click Present.
Inter Regular, Semi Bold, and Bold are required (normally available in Figma).
No network access is needed. Existing pages are preserved.

Typing and exports are represented by prepared screen states in Figma.
Use the included browser prototypes for live inputs and real PDF/DOCX downloads.
Mobile entry frames link into the desktop flows.

code.js is compiled and ready to import. code.ts is the editable source.
To rebuild from the complete project: npm ci && npm run figma:build
The plugin passed type and structural checks but still needs a native Figma run.
